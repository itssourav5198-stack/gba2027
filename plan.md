# Gaming Battle Arena 2027 — implementation plan

## Scope

Create a new Vercel-ready React/Express website that preserves the public GBA page content while restyling the presentation to follow the CBA reference experience. The public GBA content currently includes About, Event, Games, Prizes & rewards, Rules & guidelines, Supporters & partners, FAQs, Policies, Updates & Notices, Contact, and the published email/form details. The brand name becomes Gaming Battle Arena / GBA while event facts and copy stay intact.

The interaction model follows CBA: sticky navigation, section anchors, a compact mobile menu, animated reveal states, countdown/event stat cards, hoverable content cards, accessible accordions, CTA links, responsive footer, and a dedicated supporters page. The supporter page mirrors the public CBA supporter-page structure and content, adapted with GBA wording and branding. Existing public CBA email/payment/form destinations are preserved where they appear; no new payment details are invented.

## Design direction

Three possible visual directions: neon tournament broadcast (0.07), tactical dark arena editorial (0.06), and cyber-sport dashboard (0.04). Choose **tactical dark arena editorial**.

- **Design Movement:** CBA's restrained dark editorial event landing page, sharpened with esports broadcast cues.
- **Core Principles:** high-contrast hierarchy; calm surfaces with electric accents; content-first cards; every action has a clear path.
- **Color Philosophy:** near-black green-charcoal keeps the event serious and premium, while acid-lime, cyan, and signal-orange mark playable moments, links, and rewards.
- **Layout Paradigm:** wide editorial bands with asymmetric hero columns, hard section dividers, and repeated metadata rails instead of centered marketing blocks.
- **Signature Elements:** scanline texture, tournament bracket corner marks, and lime/cyan focus rings on interactive cards.
- **Interaction Philosophy:** controls feel like arena UI: visible focus, crisp hover lift, and no hidden actions; accordions keep dense event policy copy readable.
- **Animation:** slow ambient grid motion, section fade/slide reveals, count-up-like stat emphasis, and reduced-motion fallbacks.
- **Typography System:** condensed display typography for titles (fallback stack: Impact/Arial Narrow), neutral system sans for body copy, uppercase mono labels for metadata.
- **Brand Essence:** a transparent gaming competition platform where players show skill, compete fairly, and earn recognition; competitive, direct, welcoming.
- **Brand Voice:** headlines are decisive (“Enter the arena.”); CTAs are concrete (“Get event updates”, “Become a supporter”).
- **Wordmark & Logo:** GBA monogram inside a tilted arena frame with a small signal slash; use a CSS/SVG treatment rather than default plain text.
- **Signature Brand Color:** acid-lime `#c7f43a`, paired with electric cyan `#55e6ff` and signal orange `#ff845c`.

## Implementation

- `client/src/pages/Home.tsx` owns the single-page GBA content and interactions.
- `client/src/pages/Supporters.tsx` owns the dedicated supporter directory.
- `client/src/components/SiteHeader.tsx`, `SectionHeading.tsx`, `AccordionItem.tsx`, and `Countdown.tsx` provide reusable UI pieces.
- `client/src/index.css` defines the arena palette, responsive layout, motion, scanline texture, buttons, cards, and accessibility states.
- `client/src/App.tsx` maps `/` and `/supporters` with the existing router.
- `public/manus-routes.json` declares the public routes for the Webdev runtime.
- Express remains available for `/api/health`, platform configuration, and the starter auth surface; no database schema changes are needed for the public landing site.
- The contact form keeps the same fields and mailto destination as the public GBA site. Registration/support CTA destinations are kept as the published CBA/GBA mailto links where present.
- The build remains the initialized `pnpm build` Docker/Express output so Vercel-compatible production assets are generated by the existing deployment configuration.
